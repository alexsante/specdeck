# Security policy

Spec Deck is a local desktop app. It reads repositories you open. Review comments and the pull badge talk to GitHub through the `gh` CLI on your machine. The app does not store a GitHub token.

There are no releases yet. Fixes land on `main`.

## Reporting a vulnerability

Report privately. A public issue is the wrong place for a vulnerability.

Use a [GitHub security advisory](https://github.com/alexsante/speckit-mac/security/advisories/new), or email alexandersante@gmail.com if the advisory form is unavailable.

Include what you did, what you expected, and the commit you ran. You will get an acknowledgement within a few days.
